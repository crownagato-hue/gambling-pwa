【Ver.8.4 Windows起動修正】
- 「起動.bat」を全面的に簡略化・安定化しました。
- Python Launcher（py -3）を優先し、無ければpythonを使用します。
- ポートは8000ではなく8765を使用し、古いサーバーとの衝突を避けます。
- ブラウザはローカルサーバーの起動を確認してから開きます。
- サーバーの黒い画面を残す方式なので、エラーが起きた場合も内容を確認できます。
- 「起動.bat」はこのファイルがあるフォルダを自動的に作業フォルダにします。

【Windowsでの起動】
1. ZIPを展開します。
2. 展開したフォルダ内の「起動.bat」をダブルクリックします。
3. 黒い画面が表示され、数秒後にブラウザでアプリが開きます。
4. アプリ使用中は黒い画面を閉じないでください。
5. 終了するときは黒い画面で Ctrl+C → Y → Enter（表示される場合）です。

【Pythonについて】
この方式ではPCにPython 3が必要です。
「起動.bat」をダブルクリックして黒い画面が一瞬で閉じる場合は、Pythonの有無やWindowsの関連付けを確認してください。
