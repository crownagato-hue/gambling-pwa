【Ver8.16.2 P-WORLD機種データ自動更新】
・Windows PC側に「機種データ更新.bat」を追加。
・ダブルクリックするとP-WORLDの機種インデックスを取得し、各機種の詳細ページから「設置店○店舗」を確認してmachine-data.jsonを自動生成します。

・PWAはVer8.15同様、machine-data.jsonをネット優先で取得します。

【機種データ更新の使い方】
1. このZIPをWindows PCで展開します。
2. 「機種データ更新.bat」をダブルクリックします。
3. 黒い画面にP-WORLDの取得状況が表示されます。
4. 「更新完了」と表示されたらmachine-data.jsonが更新されています。
5. 「起動.bat」でPWAを起動（または起動中なら再読み込み）します。

【重要】
・PWAのブラウザからP-WORLDを直接読み取る方式ではありません。Windows側Updaterが取得→machine-data.jsonを更新→PWAが取得、という構成です。

・P-WORLD掲載情報の利用条件・権利表示に従って使用してください。
・標準設定は「最新順400件」なので、過去の全登録機種10,000件超を丸ごと保存する仕様ではありません。
・より多く取得したい場合は、コマンドプロンプトで `py -3 update_machine_data.py --pages 12` のようにページ数を増やせます。
